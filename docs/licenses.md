# Data and third-party terms

The repository code is licensed under [Apache-2.0](../LICENSE). The code licence does not grant rights to publish the underlying datasets.

- **FiinQuantX and FiinGroup data.** The SDK and vendor data are governed by FiinGroup terms. Confirm permission for public aggregates, per-bank series and exports. Keep raw vendor records and credentials private. [FiinGroup terms](https://fiinquant.vn/Home/Privacy?isShowPolicy=True)
- **Financial statements and disclosures.** Retain the bank or publisher, reporting period, source URL and page where available. Check publisher terms before redistributing reports or extracted tables.
- **Public context data.** Attribute State Bank of Vietnam material and Vietnamese legal texts to their issuing bodies. Attribute World Development Indicators to the World Bank and check the specific indicator terms. [World Bank data terms](https://www.worldbank.org/en/about/legal/terms-of-use-for-datasets)
- **shadcn and icons.** The vendored shadcn stylesheet is MIT-licensed. Lucide icons use the ISC licence. See the package manifests for the other runtime and development dependencies. [Vendored stylesheet and notice](../web/src/app/vendor/)
