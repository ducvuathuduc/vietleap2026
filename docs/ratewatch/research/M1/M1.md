## (b) Official branch counts per bank × province
- No bank publishes a machine-readable branch count by province that plain HTTP can reach: Vietcombank/MB/TPBank "mạng lưới" pages are JS-rendered store locators (checked 20/11/2026; e.g. vietcombank.com.vn renders the list via API calls from the browser). TinyFish (budget USD 3) could read them one bank at a time, but that is per-bank screen-scraping, not a dataset; not spent in M1 — OSM point counts are the map source, official counts remain a T2+ enhancement.
- SBV does not publish branch counts by bank × province either; SBV itself reorganised 63 provincial branches into 15 NHNN Khu vực regional branches (operational 2025; Khu vực 1 = Hà Nội, Khu vực 2 = TP.HCM+Đồng Nai, each region covers 3–6 provinces). Source: https://sbv.gov.vn/vi/w/ngân-hàng-nhà-nước-tổ-chức-lại-hệ-thống-chi-nhánh-khu-vực-theo-hướng-tinh-gọn-hiệu-lực-hiệu-quả (read 20/11/2026, HTTP 200).
